# Scope

This repository is the BG3 Romanian translation showcase website. Do not modify the installed game, translation packages, item-order mod, Script Extender settings, or unrelated repositories.

The owner explicitly requested migration to the root user site on 2026-10-18. The primary website source is now this repository, Gabrielish/gabrielish.github.io, deployed on GitHub Pages at https://gabrielish.github.io/ (main / root). Commit/push requested website changes directly here. Do not create another hosting site.

Preserve relative asset URLs, responsive layouts, Romanian diacritics, keyboard access and reduced-motion handling. Test browser interactions and mobile layout when changing the UI. Do not add unverified progress numbers, finished-feature claims or invented testimonials. Release archives stay in Gabrielish/bg3ro under Baldur's Gate 3 Romanian Translate; do not change the upload token scope or archive repository during website edits. GitHub downloads are primary after a release is published; Nexus https://www.nexusmods.com/baldursgate3/mods/24379 remains an alternative. The old /bg3ro/ website is a query/hash-preserving redirect. Do not modify bg3ro-old.
